# Safe python-docx List Manipulation Rules

## 1. Core Rule: Never Double-Format
When a paragraph uses Word's built-in `List Bullet` or `List Number` style, the marker (•, 1., a., etc.) is **auto-generated by Microsoft Word rendering**.
- **DO NOT** type `"• "` or `"- "` or `"1. "` in the paragraph text or runs.
- If you write `p.add_run("• Item")` with style `'List Bullet'`, Word will display: `• • Item` (Double Bullet Bug).
- Always supply only the clean text: `p.add_run("Item text without bullet prefix")`.

## 2. Modifying Existing Lists
When updating or cleaning up existing documents:
- Modify `run.text`, **NOT** `paragraph.text` directly (assigning to `paragraph.text` wipes out all formatting, bold tags, and run styling).
- Iterate `paragraph.runs` to strip unwanted prefix artifacts if present:

```python
# Safe clean-up pattern:
for para in doc.paragraphs:
    if para.style and para.style.name in ['List Bullet', 'List Bullet 2', 'List Bullet 3']:
        for run in para.runs:
            # Strip accidental manual bullet symbols
            for prefix in ['• ', '•', '- ', '* ', '▪ ', '▫ ']:
                if run.text.startswith(prefix):
                    run.text = run.text[len(prefix):]
                    break
```

## 3. Creating New Lists Correctly
```python
# Correct way to add a bullet point:
p = doc.add_paragraph(style='List Bullet')
r = p.add_run("First key point goes here")
r.bold = False

# Correct way to add a numbered list item:
p_num = doc.add_paragraph(style='List Number')
p_num.add_run("Step 1 description (Word will number this automatically)")
```

## 4. Multi-level Sub-bullets
For nested bullet points, use the appropriate indented list styles:
- Level 1: `style='List Bullet'`
- Level 2: `style='List Bullet 2'`
- Level 3: `style='List Bullet 3'`
Never simulate nesting by manually adding space prefixes like `"   • "`.

## 5. Pre-flight Verification
Before saving any modified `.docx` file, always perform a quick check:
```python
# Pre-flight assertion: verify no paragraph in 'List Bullet' starts with a bullet character
for p in doc.paragraphs:
    if p.style and 'List Bullet' in p.style.name:
        text = p.text.strip()
        assert not text.startswith(('•', '-', '*')), f"Double bullet detected in: {text[:30]}"
```
