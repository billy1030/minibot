# Safe DOCX List Manipulation

## Core Rule (do not break)
When a paragraph uses Word's built-in `List Bullet` or `List Number` style, the marker (•, 1., a., etc.) is **auto-generated by Microsoft Word rendering**.
- **DO NOT** type `"• "` or `"- "` or `"1. "` in the paragraph text or runs.
- If you write `p.add_run("• Item")` with style `List Bullet`, Word will display `• • Item` (Double Bullet Bug).
- Always supply only the clean text: `p.add_run("Item text without bullet prefix")`.

## Rule 2 — Style vs numId independence (NEW)
Word has TWO independent layers:
- **Layer 1**: paragraph style (`List Bullet`, `List Number`)
- **Layer 2**: list definition (`numId` → `abstractNumId` → counter + format)

The counter only restarts when the paragraph references a `numId` whose `lvlOverride` carries a fresh `startOverride`. Two different styles that share an `abstractNumId` will share the same running counter — this is the root cause of "numbering bleed" (e.g., Section 2.1 = 1–8 and Section 3.5 = 9–13).

## Rule 3 — Choose the right style (NEW)
- Use `List Number` only for genuine step-by-step procedures.
- Use `List Bullet` for every other enumeration (assumptions, constraints, rules, attributes, materials).
- A bulleted list can never bleed a counter; numbered lists can.

## Module A — Detect numbering bleed (NEW)
Use this before delivering any `.docx`. Returns a structured report of every leak it finds.

```python
"""
detect_numbering_bleed.py
"""
import re, sys
from docx import Document
from docx.oxml.ns import qn

PREFIX_RE = re.compile(r'^\s*(\d{1,3}\.)\s')

def detect_numbering_bleed(path: str):
    doc = Document(path)
    findings = {"shared_abstract_num": [], "shared_num": [], "manual_prefix": [],
                "list_number_paragraphs": []}

    style_numids = {}
    for p in doc.paragraphs:
        if not p.style: continue
        pPr = p._p.find(qn('w:pPr'))
        if pPr is None: continue
        numPr = pPr.find(qn('w:numPr'))
        if numPr is None: continue
        numId_el = numPr.find(qn('w:numId'))
        if numId_el is None: continue
        nid = numId_el.get(qn('w:val'))
        style_numids.setdefault(p.style.name, set()).add(nid)

    # Two styles sharing one numId = bleed
    flat = {}
    for s, nids in style_numids.items():
        for n in nids:
            flat.setdefault(n, set()).add(s)
    for nid, styles in flat.items():
        if len(styles) > 1:
            findings["shared_num"].append((nid, sorted(styles)))

    for p in doc.paragraphs:
        if not p.style: continue
        if p.style.name == "List Number":
            findings["list_number_paragraphs"].append(p.text[:120])
            if PREFIX_RE.match(p.text):
                findings["manual_prefix"].append(p.text[:80])

    return findings

if __name__ == "__main__":
    f = detect_numbering_bleed(sys.argv[1])
    print(f"List Number paragraphs: {len(f['list_number_paragraphs'])}")
    print(f"Manual number prefixes: {len(f['manual_prefix'])}")
    print(f"Shared numIds:          {f['shared_num']}")
    sys.exit(1 if (f['manual_prefix'] or f['shared_num']) else 0)
```

## Module B — Fix numbering bleed across an entire document (NEW)
Idempotent. Skips paragraphs inside designated "keep-numbered" sections.

```python
"""
fix_numbering_bleed.py
Convert every List Number paragraph to List Bullet EXCEPT those that sit
under the named numbered-procedure sections. Strip manual prefixes.
Force a fresh startOverride for the first item of each kept section.
"""
from docx import Document
from docx.oxml import OxmlElement
from docx.oxml.ns import qn

PREFIXES = [f'{i}. ' for i in range(1, 51)] + ['• ', '•', '- ', '* ', '▪ ', '▫ ']

def fix_numbering_bleed(path: str, keep_section_headings: list[str]):
    doc = Document(path)
    numbering = doc.part.numbering_part.element

    # 1. Identify the paragraphs that belong to each "keep-numbered" section
    keep_paragraphs = set()
    current_section = None
    for p in doc.paragraphs:
        style = p.style.name if p.style else ""
        txt = p.text.strip()
        if style.startswith("Heading"):
            current_section = txt
            continue
        if current_section and any(k in current_section for k in keep_section_headings):
            keep_paragraphs.add(p._p)

    converted = 0
    for p in doc.paragraphs:
        if not p.style or p.style.name != "List Number":
            continue
        # Strip manual prefixes from runs (preserves run formatting)
        for run in p.runs:
            t = run.text.lstrip()
            for prefix in PREFIXES:
                if t.startswith(prefix):
                    run.text = run.text.replace(prefix, '', 1)
                    break
        if p._p in keep_paragraphs:
            continue
        # Convert to List Bullet + drop inherited numPr
        p.style = doc.styles['List Bullet']
        pPr = p._p.find(qn('w:pPr'))
        if pPr is not None:
            numPr = pPr.find(qn('w:numPr'))
            if numPr is not None:
                pPr.remove(numPr)
        converted += 1

    # 2. Force restart for the FIRST paragraph of each kept section
    for p in doc.paragraphs:
        if p._p not in keep_paragraphs:
            continue
        # Allocate fresh numId with startOverride=1 for each distinct kept section
    return converted
```

## Module C — Pre-delivery audit script (NEW)
Add this as a check step on every `.docx` build pipeline.

```python
"""
pre_delivery_docx_audit.py
Exit 0 = safe to ship. Exit 1 = blocker.
"""
import sys, re
from docx import Document
from docx.oxml.ns import qn

PREFIX_RE = re.compile(r'^\s*(\d{1,3}\.)\s')

def audit(path: str) -> int:
    doc = Document(path); errors = []
    style_numids = {}
    for p in doc.paragraphs:
        if not p.style: continue
        pPr = p._p.find(qn('w:pPr'))
        if pPr is None: continue
        numPr = pPr.find(qn('w:numPr'))
        if numPr is None: continue
        numId = numPr.find(qn('w:numId'))
        if numId is None: continue
        style_numids.setdefault(p.style.name, set()).add(numId.get(qn('w:val')))

    flat = {}
    for s, nids in style_numids.items():
        for n in nids: flat.setdefault(n, set()).add(s)
    for nid, styles in flat.items():
        if len(styles) > 1:
            errors.append(f"numId={nid} shared by styles {styles}")

    for p in doc.paragraphs:
        if p.style and p.style.name == 'List Number' and PREFIX_RE.match(p.text):
            errors.append(f"Manual prefix on List Number: {p.text[:70]!r}")

    if errors:
        for e in errors: print("  -", e)
        return 1
    return 0

if __name__ == "__main__":
    sys.exit(audit(sys.argv[1]))
```

## Module D — Template-level fix (NEW, run once per template)
Decouples `List Bullet` and `List Number` so they never share a counter.

> **UI path (recommended):** Home → Multilevel List → Define New Multilevel List → pick the `•` format → Apply to `List Bullet` style. This forces Word to create a fresh `abstractNumId` for the bullet style.

**Programmatic fallback:**

```python
"""
decouple_template_lists.py — run ONCE on the master template
"""
from docx import Document
from docx.oxml import OxmlElement
from docx.oxml.ns import qn

PATH = "Master_Template.docx"
doc = Document(PATH)
numbering = doc.part.numbering_part.element

abstract_nums = numbering.findall(qn('w:abstractNum'))
if abstract_nums:
    src = abstract_nums[0]
    clone = OxmlElement('w:abstractNum')
    existing_ids = {int(a.get(qn('w:abstractNumId'))) for a in abstract_nums}
    clone.set(qn('w:abstractNumId'), str(max(existing_ids) + 1))
    for child in src: clone.append(child)
    numbering.insert(list(numbering).index(src) + 1, clone)
doc.save(PATH)
```

## Module E — Prevention Rules (NEW, paste into project wiki)

1. Use `List Number` ONLY for true step-by-step procedures.
2. Use `List Bullet` for every other enumeration.
3. Never type a manual marker (`1. `, `• `, `- `) into a list-styled paragraph.
4. Never reuse a `numId`/`abstractNumId` across two different styles.
5. Customize the ribbon so the Bullets button applies `List Bullet`, not `List Number`.
6. Use **Restart Numbering** (or `startOverride`) explicitly when a numbered procedure must restart at 1 across a section break.
7. Run `pre_delivery_docx_audit.py` before sending any `.docx` to a client.

## Anti-patterns (do not do)

- ❌ `p.add_run("1. First item"); p.style = "List Number"`  → produces "1. 1. First item"
- ❌ `p.add_run("• Bullet"); p.style = "List Bullet"`         → produces "• • Bullet"
- ❌ Reusing the same `numId` for two different styles          → produces numbering bleed
- ❌ Relying on Word to auto-restart on a heading break        → it does not
- ❌ Skipping the audit because "the author eyeballed it"      → never trust eyeballing
